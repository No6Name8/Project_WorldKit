# AI Edit agent traces

One JSON file per agent run, generated by `python scripts/make_agent_traces.py` from stored records. Nothing in them is generated or estimated: a field the stored record does not have is left out.

| File | What it is | Source |
|---|---|---|
| `edit_a.json` | "make the handle 2 mm thicker" | real run, 2026-11-03 rehearsal, version 1 |
| `edit_b.json` | "put a 5 mm hole through the handle side" | real run, version 3 |
| `edit_c.json` | "make the handle thinner" | real run, version 5 |
| `edit_d.json` | "make it exactly 12 cm tall" | real run, version 7 |
| `edit_e.json` | "add the text WORLDKIT on the base" | real run, version 9 |
| `refusal_wonder_declined.json` | Muse Wonder called no tool and said why | real run, 2026-11-02, with an earlier code version (see its `note`) |
| `refusal_wall_floor.json` | `thicken_part` refuses a wall under 1.2 mm | tool-level check run locally on the real rehearsal mesh; no model call |

The five edits are run 1 of each rehearsed instruction. The rehearsal ran each instruction twice; run 2 is in `pipeline/runs/rehearse/edits/versions.json` (local, gitignored) and summarised in [../DEMO_EDITS.md](../DEMO_EDITS.md).

## Fields

| Field | Meaning |
|---|---|
| `instruction` | the text typed in the AI Edit panel |
| `version_id`, `parent_version_id` | the new version and the version it was made from (`edits/versions.json`); v0 is the original and is never changed |
| `wonder_tool_calls` | the tool Muse Wonder called, its exact arguments, and the tool's own result sentence |
| `wonder_reply` | Wonder's one-sentence reply after the tool ran |
| `sam_coverage` | in how many of the run's video frames SAM 3.1 found the named part (`views_found` of `views_total`), and where that number was read |
| `deterministic_checks` | the checks of `worldkit.edit.deterministic_checks` (name, ok, detail) |
| `spark_verdict` | Muse Spark's answer on the before/after renders: `matches_instruction`, `unintended_changes`, `confidence`, `reason` |
| `decision`, `decision_reason` | accepted or rejected, and why |
| `retries`, `attempts` | retries used (at most 1) and attempts made |
| `seconds_server` | the server's time for the whole edit: Wonder, geometry, checks and Spark |
| `tokens` | token usage the Meta Model API returned for Muse Wonder and Muse Spark in this edit (no price was looked up) |
| `size_mm_before`, `size_mm_after` | bounding box of the print mesh in mm (the print mesh includes the 1.6 mm base plate) |
| `renders` | the verifier's before/after renders in the run folder (gitignored); `renders_in_repo` are JPEG copies in the repo |
| `handle_wall_mm_before_after` | handle wall thickness measured with `edit_tools.part_wall_mm`, only for edits that change the handle's thickness |
| `client` | what the browser saw: the progress stages shown and the seconds measured in the browser |
| `sources` | the files each value was copied from |

## Left out because the stored records do not have it

- The number of Muse Wonder requests per edit. Only the total is recorded: 20 Wonder calls for the 10 rehearsed edits (`docs/DEMO_EDITS.md`).
- A dollar cost. The API returns token counts only, and no price was looked up (`cost.usd` is null in `versions.json`).
- A handle wall measurement for b, d and e, which do not change the handle's thickness.
