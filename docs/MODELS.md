# Meta models in WorldKit

Three are API models on the Meta Model API (`https://api.meta.ai/v1`, OpenAI-compatible, key `MODEL_API_KEY`): Muse Spark, Muse Wonder and SAM 3.1. Three are open-weight models run on hardware we rent or call: SAM 3D Objects and VGGT on a Modal A100-40GB, and Muse Spark Open served by Baseten. Muse Image is not used. Call counts below come from the stored run reports named in each row.

## Muse Spark Open on Baseten: verification agreement

`python scripts/spark_open_agreement.py` ran the verification step of the five rehearsed edits once more through Muse Spark Open on Baseten, on the stored before/after meshes and renders (`pipeline/runs/rehearse/edits`) with the same prompt (`edit.SPARK_PROMPT`). Nothing was edited. Results: [results/spark_open_agreement.json](results/spark_open_agreement.json) (2026-11-04).

| Edit | Muse Spark (Meta API, 2026-11-03) | Muse Spark Open (Baseten) | Seconds | Same decision |
|---|---|---|---|---|
| make the handle 2 mm thicker | accept, confidence 0.85 | accept, 0.90 | 11.5 | yes |
| put a 5 mm hole through the handle side | accept, 0.95 | accept, 0.92 (second attempt; the first used all 6,000 completion tokens and returned nothing) | 22.4 | yes |
| make the handle thinner | accept, 0.85 | accept, 0.88 | 10.0 | yes |
| make it exactly 12 cm tall | accept, 0.98 | accept, 0.98 | 8.8 | yes |
| add the text WORLDKIT on the base | accept, 0.95 | accept, 0.96 | 5.8 | yes |

Agreement 5 of 5, in 6 Baseten calls. Limits of this comparison: all five edits were accepted by Muse Spark, so it shows agreement on accepted edits only; no rejected edit was compared. It is the verification step only; tool choice stays with Muse Wonder on the Meta API. Muse Spark Open reasons at length before answering, so `spark_open.MAX_TOKENS` is 16,000.
